# Marp

> Markdown-based slide-deck format. An [[obsidian|Obsidian]] plugin lets the LLM generate presentations directly from wiki content as part of the [[query-operation]] in the [[llm-wiki-pattern]].

## Overview

Authoring format where a single markdown file becomes a slide deck. Slides are separated by `---`. Useful as one of the output forms a [[query-operation|query]] can produce.

## Relationships

- Plugin for [[obsidian]].
- Output target for [[query-operation]].
