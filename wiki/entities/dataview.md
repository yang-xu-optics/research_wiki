# Dataview

> [[obsidian|Obsidian]] plugin that runs queries over page YAML frontmatter, producing dynamic tables and lists. Makes the YAML frontmatter on wiki pages in the [[llm-wiki-pattern]] queryable from inside Obsidian itself.

## Overview

In-vault query language for markdown pages with structured frontmatter. Lets you write live tables like "all source pages ingested in 2026-05, sorted by date" without leaving Obsidian.

## Relationships

- Plugin for [[obsidian]].
- Consumes the YAML frontmatter defined in [[CLAUDE]].
