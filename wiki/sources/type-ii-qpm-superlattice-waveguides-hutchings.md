# Type-II quasi phase matching in periodically intermixed semiconductor superlattice waveguides

> Demonstrates type-II QPM SHG in GaAs/AlGaAs superlattice waveguides using domain disordering by quantum-well intermixing.

## TL;DR

- Uses ion implantation and annealing to periodically intermix a superlattice and modulate chi(2) post-growth.
- Demonstrates type-II SHG for several QPM periods with 1.9 ps pulses.
- Observes high-power saturation attributed partly to third-order nonlinear effects.

## Key Claims

- Domain-disordered QPM avoids orientation-patterned growth but introduces its own fabrication/yield and nonlinear-loss issues.
- Type-II geometry matters because it aligns better with TE-polarized diode-laser integration than some type-I schemes.
