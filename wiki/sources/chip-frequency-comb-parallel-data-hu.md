# Single-source chip-based frequency comb enabling extreme parallel data transmission

> Uses an AlGaAsOI nanowaveguide comb source to drive massively parallel optical data transmission, showing why comb efficiency matters for real communications systems.

## TL;DR

- Generates a frequency comb in a non-resonant AlGaAsOI nanowaveguide with reported 66% pump-to-comb conversion efficiency.
- Demonstrates 661 Tbit/s data transmission using the comb with a 30-core fiber.
- Contrasts straight-waveguide comb robustness and efficiency with lower-efficiency resonant bright-soliton combs.

## Key Claims

- Comb sources are not just metrology objects; they can replace many parallel lasers in WDM/SDM communications.
- High conversion efficiency is a system-level metric because power-hungry laser arrays become a communications bottleneck.
